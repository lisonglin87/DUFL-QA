# 选课与教务平台

## 教务平台

- **学生端教务平台**：http://jwgl.jiaowu.dlufl.edu.cn/jxjsxsd/ （选课、查成绩、课表、学籍信息）
- **数字大外统一门户**：https://i.dlufl.edu.cn/（统一身份认证，登录后进入教务、一卡通、图书馆等系统）

## 选课的节奏

教务处每学期发布一次《选课须知》，时间通常在学期末（6—7 月发布秋季学期、12—1 月发布春季学期）：

- 2026-2027 学年第一学期选课须知：2026-07-11 发布
- 新生及其他年级公选课选课须知：2026-09-09 发布
- 学堂在线（慕课）课程使用方法：2025-07-08 发布

**注意**：新生第一次选课有单独的《新生选课须知》，与老生选课时间不同，容易错过。

## 选课类型

1. **必修课**：按培养方案自动配课，一般无需自选，但需核对课表是否有冲突。
2. **专业选修课**：按学院公布的选修课清单选择，有人数上限，先到先得。
3. **公共选修课（公选课）**：面向全校，涵盖人文、艺术、自然科学等；每学期单独发布选课须知。
4. **微专业 / 辅修**：教务处"微专业、辅修"栏目报名，跨专业系统学习一组课程。
5. **重修 / 补修**：不及格课程需重修时，按《办理课程重修的通知》在教务平台选课（2026-2027-1 学期的重修通知于 2026-07-10 发布）。

## 上课时间

学校执行统一的作息时间表（教务处"服务信息 → 作息时间"栏目可查《上课时间表》），每节课的起止时间、课间休息以该表为准；旅顺校区与中山校区作息一致。

## 常见问题

- **选课系统进不去**：先确认是否在选课开放时段，其次换浏览器（推荐 Edge / Chrome / 火狐），学校门户对 360 浏览器需要开启"极速模式"。
- **公选课没选上**：公选课名额有限，开学第一周常有退课，可关注教务平台余量；部分课程支持开学初补选。
- **课表冲突**：必修课冲突需联系开课学院教学秘书处理，不要自行放弃课程。
- **想跨专业学**：优先看"微专业、辅修"栏目，比零散选课更有体系。
